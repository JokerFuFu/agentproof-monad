# Go-to-market and user acquisition — draft

Our first intended users are small teams shipping agent-generated research, document checks and operational deliverables that require a human sign-off. We will start with one repeatable workflow: publish a delivery, send its proof package to a reviewer, and verify the accepted version before reuse.

Initial acquisition is planned through a reproducible public GitHub release, a short working Monad demo, and developer documentation showing how to wrap an existing agent output. We will invite a small, opt-in pilot group from agent-builder and Monad developer communities after release; no invitations or promotional messages have been sent yet. There are no claimed users, customers, revenue or partnerships.

Pilot evaluation will measure time to complete the first verified receipt, successful independent verification, repeat publication/review, and reasons users abandon the flow. We will use those observations to improve the package handoff and integration API.

The initial prototype will be free to try with test-only funds. Pricing, production operations and paid transactions are outside this hackathon scope. Further expansion will depend on evidence that immutable version identity and review history help real teams, rather than on speculative token incentives.
